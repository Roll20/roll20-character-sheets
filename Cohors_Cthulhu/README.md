# Cohors Cthulhu sheet

The Roll20 character sheet for Cohors Cthulhu, a Roman-legion / Cthulhu
Mythos horror game built on Modiphius's 2d20 System.

Maintained by Han Vanholder. To report a problem or suggest a feature, open
an issue on [Roll20's sheet repository](https://github.com/Roll20/roll20-character-sheets/issues)
with `[Cohors Cthulhu]` in the title.

## Features

- **One chat card per roll**: click an Attribute, Skill, Focus, Weapon or
  Spell to roll it. The card shows the dice, target number, successes,
  Complications and the Momentum generated and spent, with a weapon's
  damage or a spell's cost and damage rolled in the same message.
- **Focus rolls**: a Focus crits on every die at or under the skill's
  ranks. A spell cast with its skill's magic focus (e.g. Survival:
  Mysticism) does too.
- **Spells**: picking a spell fills in its mechanics. The list offers the
  character's Magical Tradition; spells learned from other traditions stay,
  with a note naming their tradition. Attack spells roll
  Power plus their damage, and Dabblers choose Power 1 or 3 at the cost of
  Threat.
- **Skills**: two compact columns showing the Focuses the character has
  learned; Edit Focuses shows them all.
- **Stress, Fatigue, Injury and Fortune trackers**. Resist Fatigue clears
  Fatigue on a success; injury boxes past the "Defeated at" limit are
  greyed out.
- **Weapons, armor and talents** fill in their stats from a dropdown. A
  player character's talent list shows only the talents they qualify for.
- **Talent bonuses**: talents such as Warrior Born or Unyielding add their
  bonus to Courage, Max Stress or the injury limit while the character has
  them.
- **Characteristic** dropdown, with a **Secret** box (checked by default)
  for one the character hasn't revealed yet.
- **NPC sheets**: the Player / NPC switch beside the tabs turns any sheet
  into a Trooper, Toughened or Nemesis NPC, with stat block values,
  special rules, mental attacks and the Mythos spellbooks. Adversaries roll
  with Threat instead of Momentum.
- **Macro bar**: drag any roll button onto it.
- **Dark Mode** and **printing** are supported.

## Companion API script (optional)

The sheet works on its own. The optional
[Cohors Cthulhu Companion](https://github.com/Roll20/roll20-api-scripts/tree/master/Cohors_Cthulhu_Companion)
Mod adds shared Momentum and Threat pools kept up to date by every roll,
token actions for weapons and spells, and NPC import. Mods need a Roll20 Pro
subscription for the game's creator.

## Modifying the sheet

The sheet is built with [k-scaffold](https://kurohyou-studios.github.io/k-scaffold/);
see its documentation for setting up and building. All source files are in
`source/`. `Cohors_Cthulhu.html` and `Cohors_Cthulhu.css` are generated by
`npm run build`, so change the source and rebuild rather than editing them.

### Adding spells, weapons, armor, talents and characteristics

Every list on the sheet comes from data in `source/`. Rebuild after any
change below.

#### A new spell

1. **`source/data/spells.json`**: add an entry under its tradition's key
   (`runic`, `oracular`, `celtic`, or the NPC-only Mythos tomes `cthulhu`,
   `mormo`, `nyarlathotep`, `yog_sothoth`):

   ```json
   "Mist of Avernus": {
     "skill": "Survival",
     "difficulty": "2",
     "cost": "4 Drain, Piercing 1",
     "duration": "Power rating in rounds",
     "category": "Manifestation spell"
   }
   ```

   `cost` starts with the number of Challenge Dice, followed by the cost's
   damage effects. `difficulty` starts with the number; anything after it
   (e.g. an opposed test) is shown as text.

   An **attack spell** also gets a `"damage_effects"` in a weapon's format:
   the base rating in Challenge Dice, then the effects (`"2, Piercing 1"`).
   The casting roll rolls the caster's Power plus that rating.
   `source/data/spells.schema.json` describes every field, and the build
   checks `spells.json` against it.
2. **`source/views/_spells.pug`**: add the name to that tradition's Spell
   Name dropdown (the `+select` with class `.cc-spell-name-<tradition>`).
   Write each option out; generating them in a loop doesn't work in
   k-scaffold:

   ```pug
   +option({value: "Mist of Avernus"})
     | Mist of Avernus
   ```

   The option value must match the JSON key exactly.
3. *Only if needed*, also in `_spells.pug`: list the spell in
   `ccSpellCostThreatPerEffect` if each Effect on its cost adds Threat, or in
   `ccSpellMomentumCostDice` if Momentum spent on it adds dice to its cost.

Imported NPCs need nothing else: a spell given by name in an NPC file gets
its details from `spells.json` when the sheet is first opened.

#### A new weapon

1. **`source/views/panels/_weapons_panel.pug`**, at the top: add a profile
   to `ccMeleeWeapons` or `ccRangedWeapons`:

   ```js
   'Trident': {focus: 'Melee Weapons', reach_range: '2', damage_effects: '4, Piercing 1', size: 'Major', qualities: ''},
   ```

   `damage_effects` is the damage in Challenge Dice, then the damage
   effects. `Archery` and `Thrown Weapons` roll as ranged (Coordination),
   any other focus as melee (Agility).
2. Same file: add the name to the players' dropdown (`.cc-weapon-name-select`)
   and the NPC suggestion list (`datalist#cc-weapon-options`):

   ```pug
   +option({value: "Trident"})
     | Trident
   ```

   ```pug
   option(value='Trident')
   ```
3. **The Companion script**: copy the profile into `ccWeaponProfiles` in its
   NPC IMPORT section, so imported NPCs can name the weapon.

#### New armor

1. **`source/views/panels/_armor_panel.pug`**, at the top: add a profile to
   `ccArmorProfiles`:

   ```js
   'Lorica Plumata': {resistance: '3', qualities: 'Heavy'},
   ```
2. Same file: add the name to the players' dropdown (`.cc-armor-name-select`)
   and the NPC suggestion list (`datalist#cc-armor-options`), as for
   weapons.
3. **The Companion script**: copy the profile into `ccArmorProfiles` in its
   NPC IMPORT section.

#### A new talent

1. **`source/data/talents.json`**: add an entry. The Talents list is
   generated from this file and sorted automatically:

   ```json
   "Iron Discipline": {
     "keywords": "Soldier, Resilience",
     "requirements": "Resilience 2+",
     "bonuses": [
       {"target": "courage", "value": 1}
     ]
   }
   ```

   If two talents share a name, give them distinct keys such as
   `"Scotopia (Robber)"`.
2. **Requirements decide who sees it.** A player character's Talent dropdown
   lists only talents whose requirements the character meets. `requirements`
   is a list of clauses separated by `;` or `,`, all of which must be met:

   | Clause | Example |
   | --- | --- |
   | Archetype | `Soldier archetype` (or just `Mystic`) |
   | Culture / caste | `Greek culture`, `Noble caste` |
   | Skill ranks | `Medicine 3+`, `Academia or Engineering 3+`, `1+ ranks in Medicine` |
   | Other talents | `Tracker talent`, `Backstabber talent or Subtle Step talent` |
   | Spellcaster limit | `can't already have a Spellcaster-keyword talent` |

   A leading `plus` is ignored, and `Advanced` adds no condition. A
   specialization in `keywords` (`Legionary`, `Medicus`...) also requires
   that specialization. Any other wording stops the build with an error
   naming the talent: fix the text, or add the pattern to
   `ccParseRequirements` in `source/views/panels/_talents_panel.pug`.

3. **Bonuses**: `bonuses` lists what the talent adds to a calculated
   value, and is `[]` when it adds nothing. The sheet adds a player
   character's talent bonuses whenever it calculates the value, so picking
   the talent adds them and changing or deleting the row takes them off.
   Each entry has a `target` (`courage`, `stress_max` or `injuries`, the
   number of injuries before defeat) and one of three modes:

   | Mode | Example | Effect |
   | --- | --- | --- |
   | `add` (the default) | `{"target": "courage", "value": 2}` | adds `value` |
   | `highest` | `{"target": "courage", "skill": "academia", "mode": "highest"}` | the skill's ranks, if higher than the talents' added total (Platonist) |
   | `set` | `{"target": "courage", "value": 6, "mode": "set"}` | fixes the final value (Numb to the Horrors) |

   A new target also needs code: see `ccTalentBonus` in
   `source/views/panels/_talents_panel.pug` and the calculation it feeds.

Talents named in an NPC file get their keywords and requirements from
`talents.json` when the sheet is first opened.

#### A new characteristic

**`source/data/characteristics.json`**: add its name. The Characteristic
dropdown lists these.
