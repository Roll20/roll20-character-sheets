# Broken Blade, Sundered Shield (BBSS)

A Roll20 character sheet implementation for the tabletop roleplaying game Broken Blade, Sundered Shield.

## Credits

**Original Game Design and Character Sheet Design:** Brian Lujan

**Roll20 Conversion and Digital Implementation:** David Barnard and Brian Lujan

The original game mechanics and character sheet design remain credited to Brian Lujan.

## Features

- Interactive character information fields
- Skill progression checkboxes
- Personality and Temperament selections
- Specialties and Gear entries
- Coins and Experience fields
- Notes area with text wrapping and scrolling
- Roll20 character avatar integration

## Development Status

Version 1.2 – Functionally tested in Roll20.

This implementation is intended to reproduce the original BBSS character sheet digitally while preserving its visual design.
