Powers

Psychic powers ask for effective Psy Rating when used and add 5 x that to the test target, and PR in the bolt profile uses it (3xPR works too). With a bolt type set, Use rolls the Focus Power test as the attack and shows hits, location and damage on a success. For the test, pick a characteristic, or name a skill (e.g. Medicae) to roll against that skill instead. Navigator mastery applies its penalty automatically. Set the test to None for powers that don't roll.
