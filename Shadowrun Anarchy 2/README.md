# Shadowrun Anarchy 2

Community character sheet for Roll20, development version 26.

## Files

- `ShadowrunAnarchy2.html`: sheet markup, roll templates and sheet workers.
- `ShadowrunAnarchy2.css`: layout and styling.
- `translation.json`: English source strings.
- `translations/de.json` and `translations/fr.json`: German and French translations.
- `sheet.json`: Roll20 metadata.
- `preview.png`: local Chromium rendering with fictional example values; not a live Roll20 screenshot.

## Before submitting a pull request

- Enter the contributor's numeric Roll20 profile ID in `sheet.json` (`roll20userid`) and confirm the author credit.
- Replace the local preview with a screenshot from the actual Roll20 sheet if necessary.
- Test rolls, repeating sections, threshold reports and layout in Roll20 (Chrome and Firefox).
- Review German and French terminology and remaining non-localized dynamic strings.
- Review intellectual property and repository submission requirements.

This is an unofficial community development version, not a publisher-endorsed sheet. Keep attribute names stable to preserve existing character data.
