# Shadowrun Anarchy 2

Community character sheet for Shadowrun: Anarchy 2.0 on Roll20.

## Features

- Integrated dice rolls with Advantage, Disadvantage, Risk Dice and Risk Reduction.
- Character attributes, skills, specializations and custom skills.
- Edge management, wound tracking and damage thresholds.
- Amps, weapons, magic, matrix, vehicles, contacts and gear.
- Physical, Astral and Virtual initiative bonuses.
- Context-aware roll defaults for Matrix tests.
- Optional character and equipment images with chat sharing.
- Centralized character configuration.
- Integrated documentation and macro examples.
- Internationalization support.

## Files

- `ShadowrunAnarchy2.html`: Sheet markup, roll templates and sheet workers.
- `ShadowrunAnarchy2.css`: Layout and styling.
- `translation.json`: English source strings.
- `sheet.json`: Roll20 metadata.
- `preview.png`: Character sheet preview.

## Localization

English is the source language. Additional translations are managed through Roll20's Crowdin workflow.

German and French translations are in preparation.
