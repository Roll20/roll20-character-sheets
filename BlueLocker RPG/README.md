# BlueLocker RPG

Character sheet for the original **BlueLocker RPG** system, created by MiguelGO and published by LHUB Studios.

## Features

- Automated character sheets for outfield players and goalkeepers.
- Attributes, progression, play styles, and talents.
- Flow, Metavision, and Predator Eye.
- Secret Weapon and custom roll templates.
- Core functionality that works independently of Mod Scripts.

Rules and materials: https://lhub.store/products/manual-blue-locker-2026
